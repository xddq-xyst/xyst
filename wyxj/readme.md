# 未央仙境探索路线
作者: 织梦山11/20服 大眼松鼠

## 引言
在未央仙境中，一个占据2x3格子的大怪有概率掉落传说法象碎片，这是白嫖传说法象的一个重要来源。
然而，在网络上没有见到过有人讨论如何尽可能多地触发2x3（仅作者所知），因此我们将在下面去讨论这一点。

## 方法
#### 目标
在满足未探索格不包含2x3的条件下使得已探索格数量最小，且已探索格之间必须是连通的

#### 直觉
假设大网格是简单的nxm矩阵，将其划分为规则的(n/2)x(m/3)个不相交的2x3格，
每个2x3中至少要有一格被探索，这样需要大约1/6 mn格。
而每个被探索的格子之间应当是连通的，一个最简单的策略就是每一行的2x3之间连一条线，再用一列把每行连起来，
这样大约是1/3 mn格，直觉上这也是最优的。

#### 分析
这里提供一个分析角度：将每个落于2x3的单元格连起来是复杂的，因为每个单元格在2x3中的位置是不固定的。
但可以将2x3整体看成一个单位格，而修改连通花费，即横向跨越一个2x3的花费为2，纵向跨越一个2*3的花费为3（原来都是1）。
从这个角度看，探索策略应当尽量多地横向走而不是纵向走。
